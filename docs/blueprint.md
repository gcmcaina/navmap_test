# **App Name**: Plate Gallery

## Core Features:

- File Upload: Upload a CSV or XLSX file containing license plate recognition data (plate number, image URL, year, make and model).
- Data Display: Display the license plate data in a sortable, searchable table format with links to each image.
- Image Grid: Transform image URLs into a user-friendly grid of thumbnails.
- Image Shortcuts: Open the selected image in a modal or new tab with shortcuts (e.g., copy plate number, download image, open original URL).
- AI-Powered Search Suggestions: Utilize an AI-powered tool to suggest relevant search queries (e.g., 'vehicle models 2018,' 'common modifications for Camry') based on extracted data like make, model and year, in order to locate further information online.
- Filter Functionality: Enable filtering by year and model.
- Filtered Data Export: Enable downloading of filtered dataset as new CSV/XLSX.

## Style Guidelines:

- Primary color: Deep Blue (#293B5F) to evoke trust and professionalism.
- Background color: Light Gray (#D4D4D4) for a clean and neutral backdrop.
- Accent color: Warm Orange (#E67700) for interactive elements and highlights to draw user attention.
- Body and headline font: 'Inter' sans-serif for a modern, objective feel.
- Use minimalist icons for actions (download, copy, search).
- Responsive grid layout that adapts to different screen sizes, maintaining readability and ease of use on both desktop and mobile devices.
- Subtle transitions and animations for feedback on user interactions (e.g., highlighting selected images, loading states).
